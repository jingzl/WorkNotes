

**REA**
[morluto/rea: Reverse engineer anything with agents, from app behavior down to native binaries.](https://github.com/morluto/rea) 逆向工程一切
一个 **本地化逆向工程平台**（npm `rea-agents` v6.4.0，MIT），把「AI Agent 驱动的逆向调查」做成统一 **CLI + MCP 服务器** 双入口。
**功能特点**
- **六种工具形态**：inspect / search·list / trace / compare / workflow / observe·capture，按「分析者问题」而非引擎能力设计。
- **20+ 目标格式**：原生二进制、JS/Electron、.NET、APK/ADB、固件、PCAP、EVM、WASM、SQLite、Flutter、Harmony、JEB 等。
- **一键接入 Agent**：`npx rea-agents setup` 写 MCP 注册 + 配套调查 skill；支持 **24 个客户端**（Claude Code、Codex、Cursor、Gemini CLI、Copilot、VS Code、WorkBuddy、DeepSeek Harness…）。
- **工程化程度高**：`src/` 约 **41.6 万行 TS / 1858 文件**，**792 个测试文件**分 acceptance/boundary/conformance 等 project，oxlint+oxfmt+knip+jscpd+架构守卫+Stryker 变异测试。
