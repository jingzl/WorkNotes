# 一把手 vs 二把手 对比表

## 主题：二把手帮大家赚钱

| 对比维度     | 一把手   | 二把手   |
| -------- | ----- | ----- |
| **关注点**  | 管结果   | 管过程   |
| **状态**   | 在思考   | 在做事   |
| **职责**   | 负责战略  | 负责落实  |
| **角色定位** | 给员工造梦 | 帮员工圆梦 |
| **方向问题** | 去哪里   | 怎么去   |
| **分配逻辑** | 给大家分钱 | 帮大家赚钱 |

| 层级 | 一把手（橙色）—— 决策层 | 二把手（蓝色）—— 执行层 |
|------|------------------------|------------------------|
| **核心定位** | 思考者、决策者 | 执行者、推动者 |
| **管理对象** | 结果导向 | 过程导向 |
| **价值传递** | 通过分钱激励员工 | 通过赚钱成就团队 |
| **工作方式** | 造梦、定方向 | 圆梦、找路径 |

### 💡 总结

- **一把手** 决定「**去哪里**」，负责画饼和分钱，靠战略与愿景驱动团队；
- **二把手** 负责「**怎么去**」，负责落实和赚钱，靠执行与结果验证战略。

> 一把手造梦，二把手圆梦；一把手分的是"愿景"，二把手赚的是"真金白银"。
